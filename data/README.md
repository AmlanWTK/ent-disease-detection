# Datasets

Datasets are NOT stored in this repo. Download them and put them in these folders.

| Folder | Dataset | Images | Link |
|---|---|---|---|
| `ear/chile/` | Ear Imagery Database (Viscaino et al.) | 880, 4 classes | https://figshare.com/articles/dataset/Ear_imagery_database/11886630 |
| `ear/turkey/` | Eardrum dataset (Polat) | 282, normal/abnormal | https://figshare.com/articles/dataset/eardrum_zip/13648166 |
| `nose/nasal_polyp_ct/` | NasalPolyp-CT-Sinonasal | 453 CT, 2 classes | https://data.mendeley.com/datasets/ph4vffmzcn/1 |
| `mouth/mod/` | Mouth and Oral Diseases (MOD) | 517, 7 classes | https://www.kaggle.com/datasets/javedrashid/mouth-and-oral-diseases-mod |
| `mouth/sri_lanka/` | Oral cavity images (Piyarathne et al.) | 3,000, 4 classes | https://doi.org/10.5281/zenodo.10664056 (request access) |

Cite the original authors when you publish.
